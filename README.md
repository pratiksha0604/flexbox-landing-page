
## Task Implementation Steps

1. Set up the HTML skeleton with header, main and footer sections
2. Apply Flexbox containers to arrange navigation and hero content
3. Add media queries to adjust layout for mobile screens
4. Test the page on different device widths and refine spacing

## How to Run

1. Clone or download this repository
2. Open the `flexbox-landing-page` folder
3. Double-click `index.html` to open it in your browser

## Responsive Breakpoints

| Screen | Width | Layout changes |
|--------|-------|----------------|
| Desktop | Above 768px | Navigation in one row, hero text and image side by side |
| Tablet | Up to 768px | Navigation stacked, hero in a single column |
| Mobile | Up to 480px | Smaller heading, avatar and button sizes |

## Testing

Tested in browser DevTools (`F12`, then `Ctrl + Shift + M`) at 1200px, 768px and 375px widths.
